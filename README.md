## Backend

The initial FastAPI backend is in [backend/](backend/). Setup instructions and current API scope are in [backend/README.md](backend/README.md).

Current working scope: authenticated video upload, per-user video/clip access checks, manual timestamp-based MP4 export, and clip download/history. These code paths still require live deployment testing. AI highlight detection, player/facecam tracking, automatic subtitles, and AI-generated titles/descriptions are not implemented yet.
